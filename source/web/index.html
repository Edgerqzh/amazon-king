    店铺分析

    只读 · 索评需逐批确认

    按亚马逊财务流水算每个 SKU 的利润：销售额 + 运费等收入 + 促销 + 亚马逊费用 + 退款 − 增值税 − 成本。费用和退款是负数。成本请在下面的“单件成本”里按 SKU 填（采购 + 头程，按站点币种），不填的 SKU 不扣成本。亚马逊财务数据一般晚 1–2 天，读取约需 10–40 秒。

    每行一个：SKU, 单件成本。成本为 0 也要写 0；要删除某个 SKU 的成本就只写 SKU、逗号后留空。

    SKU销量 / 退款销售额亚马逊费用退款 / 促销增值税成本利润利润率

    读取亚马逊物流退货报告和同期订单报告，按 SKU 统计退货数量、退货率和退货原因。退货率 ≥ 10% 且至少 3 件，或多数退货是质量类原因（缺陷、与描述不符、缺配件等）的商品会标出来。生成报告一般要 1–5 分钟。

    SKU退货 / 销量退货率主要原因退回去向

    列出亚马逊标了错误或警告的全部商品，不能售卖的排在最前面。最多读 500 个。

    SKU状态问题

    列出发往亚马逊仓库的货件和状态，并对比发出与接收的数量。已完成但少收的货件排在最前面，可以去卖家后台核对或申请赔偿。最多读取最近 20 个货件的明细。
