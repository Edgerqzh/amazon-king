# 无敌亚马逊大王

亚马逊卖家用的小团队工具：管理原始模板、识别库存类别、填写上架表格、调价改库存、看订单和销售。主要面向 AE（阿联酋）和 SA（沙特）站点。

## 第一次使用

1. **安装 Python**：到 <https://www.python.org/downloads/> 下载并安装 3.9 或更新版本。安装第一页记得勾选 **“Add python.exe to PATH”**。
2. **下载本软件**，二选一：
   - 装了 Git：在想放软件的文件夹里打开终端，运行

     ```bash
     git clone https://github.com/Edgerqzh/amazon-king.git
     ```

   - 没装 Git：在本页点绿色的 **Code → Download ZIP**，然后解压。
3. **启动**：打开 `source` 文件夹，双击 **`启动.bat`**。
   - 第一次启动时，会在黑色窗口里让你创建管理员账号。密码至少 12 位，输入时不显示。
   - 之后浏览器会自动打开软件。要是没打开，手动访问 `http://127.0.0.1:8765`。
   - 使用期间别关那个黑色窗口，关了软件就停了。
4. **同事一起用**（可选）：双击 `启动-局域网共享.bat`，窗口里会显示同事访问的地址。详见 [公司局域网使用指南](source/公司局域网使用指南.md)。

## 更新到最新版

用 git 下载的，在 `amazon-king` 文件夹里运行：

```bash
git pull
```

用 ZIP 下载的，重新下载解压，再把旧文件夹里的 `source/.data` 复制到新文件夹的同一位置。

模板库、账号这些数据都存在 `source/.data` 里。这个文件夹不在 git 里，`git pull` 不会改动它，也不会把它上传。

## 连接自己的亚马逊店铺（可选）

不连接亚马逊也能管理模板、填写表格。想用预检、上架、调价、订单这些功能，需要用**你自己的**卖家账号去申请 SP-API 私有开发者，再到软件的“设置 → 亚马逊连接”里填写凭证。凭证只保存在你自己的电脑上，别发给任何人，也别截图。具体步骤见 [source/README.md](source/README.md) 里的“亚马逊接口”一节。
